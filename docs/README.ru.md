# OpenPhoto

[English](../README.md)

Открытый фоторедактор с локальным ИИ для сортировки, отбора, обработки и ретуши фотографий. Вычисления выполняются на вашем компьютере.

## Возможности

- Sony ARW/JPEG и связанные пары, сравнение, рейтинги и рекомендации отбора.
- Обратимая проявка, цвет по референсам, кадрирование и пакетные правки.
- Ретушь лица и тела с регулируемой силой и защищёнными областями.
- Обработка съёмки одной задачей с паузой и повтором ошибок.
- Экспорт JPEG, TIFF16, XMP рейтингов и собственных рецептов.

Исходники сохраняются на месте. Удаление из каталога не удаляет фотографии. После подготовки зависимостей, движков и моделей обработка работает без интернета.

## Запуск

0.2.5 — предварительная исходная версия для Windows x64. Добавлены удаление съёмок, восстановление кадров повторным импортом, короткое обучение, управление масштабом и перемещением, числовые настройки и гистограмма превью. Интерфейс сейчас на русском. Результаты ИИ требуют проверки; автообрезка по умолчанию выключена. PSD используется как сведённый референс, без редактирования слоёв.

Публичный установщик ожидает проверки чистой Windows и условий распространения компонентов. Пока используйте исходники. Нужны Python 3.12, uv, Node.js 22, Git и Microsoft WebView2. Полное окружение скачивает несколько гигабайт зависимостей.

```powershell
git clone https://github.com/ANTIANT1/OpenPhoto.git
cd OpenPhoto
uv sync --frozen --extra desktop --extra ml --extra dev
.venv\Scripts\python scripts\install_engines.py
.venv\Scripts\python scripts\install_models.py
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
.venv\Scripts\python -m openphoto
```

Добавьте съёмку и выберите «Обработать съёмку» или «Обрабатывать вручную». В настройках автоматического маршрута можно отключить ретушь и включить JPEG-экспорт. Проверьте результаты и сохраните их в отдельную папку.

P / X — отбор и отклонение, 1–5 — рейтинг, Ctrl+A — весь фильтр, Delete — убрать из каталога, Ctrl+Z — отменить действие в сетке. Ctrl+колесо или +/− меняют масштаб; Ctrl+0 — по окну, Ctrl+1 — 1:1. Пробел+мышь перемещает фото даже при кадрировании, B переключает до/после, Ctrl+Enter применяет правки. Правки также сохраняются перед переходом и экспортом.

Корзина рядом с названием убирает съёмку из списка. Карточки доступны в «Удалённых»; восстановление или повторный импорт возвращают их вместе с правками и рейтингами. Исходные файлы сохраняются.

Без выбранного референса автоматическая обработка сохраняет цвет и экспозицию. Pinterest пока не подключён: используйте локальные изображения в профилях референсов. Обучение отбора по оценкам и сравнениям — отдельная функция.
